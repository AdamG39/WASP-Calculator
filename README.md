# WASP-Calculator

A simple calculator program written in a custom assembly language for use with the WASP processor simulator. This project was done as part of a university module at Northumbria University and the requried assembler and simulator are not publically available and therefore this project is not intended to be built and ran and is merely a display of the source code. This program achieved a score of 50 out of 50 for its required assignment. This calculator includes support for addition, subtraction, multiplication, division and modulus of signed 16-bit integer values as well has basic error handling and multiple calculations without the need to restart the program.
